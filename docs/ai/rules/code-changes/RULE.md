## ⚠️ NON-NEGOTIABLE CODE CHANGE RULE

- **NEVER** make changes to any source code repositories referenced in this project without human approval.
- In chat, **NEVER** propose making immediate changes to source code. The human will provide specific instructions and approval for code changes.

> [!NOTE]
>
> This rule does not apply to generating documentation, where recommendations and proposals are specfically requested in instruction documents or chats with human.
