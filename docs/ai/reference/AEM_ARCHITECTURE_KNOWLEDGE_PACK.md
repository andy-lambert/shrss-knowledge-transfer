# AEM Architecture Knowledge Pack for AI Agents

Purpose: Provide a curated set of high‑value documentation topics that
agents should prioritize when working with Adobe Experience Manager
projects.

This pack represents a condensed knowledge base derived from official
Experience League documentation.

## Core Architecture Concepts

Agents should understand:

-   Sling framework
-   OSGi modular runtime
-   JCR repository architecture
-   Dispatcher caching layer
-   Cloud Manager CI/CD pipeline
-   Adobe Experience Cloud integration

## Agent Best Practices

Agents should:

-   Align architecture with official Adobe patterns
-   Prefer Sling Models over JSP or legacy patterns
-   Follow Dispatcher caching recommendations
-   Ensure CI/CD aligns with Cloud Manager pipeline rules
-   Reference official documentation when generating code or design
    guidance
