# Develop Websites and Components in Adobe Experience Manager (AEM)

## Part 1 - AEM Technical Basics

Part one of this course begins with Adobe Experience Manager Technical Basics, teaching project creation through a Maven archetype and development with an Integrated Development Environment (IDE). Participants will learn the fundamentals of Sling content rendering, the Java Content Repository (JCR) structure, as well as Adobe’s templating language, HTL. Throughout this course, participants will learn best practices for using AEM Sites Components and how to style them with the ui.frontend module. Participants will also learn how to create editable templates and pages, design Core Components, use the Style System, and create custom components. This course also shows how to implement the Adobe Client Data Layer, which allows an AEM Site to send data to Adobe Launch or any other third-party-service.

**After completing part one of this course, you should be able to:**

- Understand content rendering and HTL.
- Design, develop, and extend components.
- Extend Core Components.
- Implement custom components.
- Work with page templates.
- Understand Cloud Manager basics.

## Part 2 - Develop Websites and Components

This is part two of the course. Please complete part one before proceeding with this portion.

In part one, you learned about AEM Technical Basics, including best practices, AEM architecture, AEM as a Cloud Service, installing and configuring AEM, and using Maven, Visual Studio Code, and other development tools to configure and maintain AEM.

Part two of the course focuses on **Develop Websites and Components** materials.

**After completing part two this course, you should be able to:**

- Describe the key concepts of AEM site development.
- Create and use a Maven project in an IDE.
- Use HTL to render pages.
- Explain sites components.
- Extend Core Components using the Core Component delegation pattern.
- Create client-side libraries.
- Implement custom components.
- Work with page templates.
- Add Adobe Client Data Layer to any component.
